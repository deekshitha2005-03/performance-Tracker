# 📊 Performance Tracker Dashboard – Power BI Project

## 🚀 Project Overview
This project is an interactive **Performance Tracker Dashboard** built using **Power BI** to monitor business performance, analyze KPIs, and generate actionable insights through dynamic visualizations.

The dashboard is designed to help users track performance metrics efficiently with interactive filtering, comparisons, and trend analysis.

---

## 🎯 Objectives
- Monitor overall business performance
- Track KPIs effectively
- Compare performance across categories/products
- Visualize trends and patterns
- Enable data-driven decision-making

## 📂 Dataset Information

The dashboard is built using the **D6.csv** dataset containing transactional sales and customer data used for performance analysis and business insights generation.

### 📊 Dataset Overview

The dataset includes **1000 records** and **17 columns** covering:

* Invoice Details
* Branch Information
* City Locations
* Customer Types
* Gender Distribution
* Product Categories
* Unit Prices
* Quantity Sold
* Tax Calculations
* Total Sales
* Payment Methods
* Gross Income
* Customer Ratings

### 📌 Key Columns Used

* `Invoice ID`
* `Branch`
* `City`
* `Customer type`
* `Gender`
* `Product line`
* `Unit price`
* `Quantity`
* `Total`
* `Payment`
* `Gross income`
* `Rating`

### 📈 Analysis Performed

* Sales Performance Analysis
* Customer Behavior Analysis
* Product Line Comparison
* Payment Method Insights
* Revenue & Profit Tracking
* Branch-wise Performance Monitoring
* Customer Rating Evaluation

### 💡 Business Insights Generated

* Identified top-performing product categories
* Compared branch and city-level sales performance
* Analyzed customer purchasing patterns
* Evaluated payment preferences
* Tracked revenue trends and profitability

The dataset was cleaned and transformed using:
